# Design System Color Tokens

Defined in `src/assets/main.css`:

| CSS Property | Hex Value | Usage |
| :--- | :--- | :--- |
| `--bg-dark` | `#0b0f17` | Main page background |
| `--bg-surface` | `#121826` | Card container surface |
| `--bg-glass` | `rgba(18,24,38,0.75)` | Translucent glass panel |
| `--border-subtle` | `rgba(255,255,255,0.08)` | 1px border separator |
| `--border-glow` | `rgba(99,102,241,0.3)` | Primary glowing border |
| `--accent-primary` | `#6366f1` | Electric Indigo / Violet accent |
| `--accent-emerald` | `#10b981` | Revenue won & success states |
