# Glassmorphic Utility Classes

Defined in `src/assets/main.css`:

- `.glass-panel`: Applies backdrop blur (`16px`), glass background, and subtle border.
- `.glass-panel-hover`: Elevation shadow and glowing border highlight on hover.
- `.btn-primary`: Gradient button (`#6366f1` -> `#8b5cf6`) with shadow glow.
- `.badge-[stage]`: Status pills (`badge-lead`, `badge-qualified`, `badge-won`, `badge-lost`).
